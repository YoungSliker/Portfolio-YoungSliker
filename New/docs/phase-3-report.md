## 交互
桌面左侧约四分之一为固定年份导航，右侧为经历。原生滚动驱动单一当前节点与年份高亮，细线逐渐填充橙色；回滚恢复。每帧最多测量一次，只有节点变化才更新 React 状态。手机采用单列，所有经历默认可读，横屏取消侧栏固定。减少动态效果时年份跳转直接定位。

三个项目链接使用 #work=ID，定位并聚焦既有作品概况卡片；刷新、前进后退保留链接含义。尚未假装进入未开发的图谱或完整案例详情，后续 PHASE 5、6 再扩展。
