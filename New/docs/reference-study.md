# 首屏参考研究与改版决策
日期：2026-10-17。基于本次实际打开的三个参考页，不沿用 PHASE 1 的通用排版。

## 观察证据
- [Numerous](https://portfolio-site-r7s5qgb7.wegic.net/)：已看到首屏与页面 DOM。白底、横向大标题、四张倾斜的作品贴纸围绕标题，中央介绍下方有鼠标轮廓提示。关键是作品与文字的前后层次，而非仅有巨大字号。
- [Vesper](https://vesper-space.aura.build/)：已看到首屏与实际预览 iframe 的 DOM。中央大标题、下方滚动提示、底部进度形成完整入口。检查渲染 iframe 的公开 CSS 与动画配置：提示线循环伸缩；滚动时提示先淡出，标题向上退场；随后 pinned arrival 引出叙事文字。实际滚动工具曾超时，连续动态节奏未完整人工观测，不能声称已完整体验全站。
- [Afterglow](https://afterglow.aura.build/)：已看到关闭电源的首屏，点击“Switch main power on”后确认标题点亮、导航和滚动进度出现。RESTORE MAIN CURRENT 是启动交互提示，不是单纯的滚轮说明。借鉴动作反馈与下一步提示，不把电源门槛照搬给作品集。
- 三站都没有被复制源码、品牌图像或整体视觉；公开页面片段仅用于理解实现方法。

## 此轮设计
1. 首屏中心采用完整 YOUNGSLIKER 字标；四周放置绥远方志、库伦荞麦、矿山*生态、微元灵溯真实图像，采用不等尺寸和旋转，形成空间层次。
2. 首屏底部居中放置“SCROLL TO DISCOVER / 向下滚动，进入创作档案”，包含向下移动的橙色短轨迹与箭头，且可点击进入 About。无需猜测页面可以滚动。
3. 左下进度线反馈封面阅读过程。普通滚轮驱动原生页面滚动，使用 CSS sticky + GSAP scrub，不拦截 wheel。
4. 开始滚动后提示先退出，标题和四张作品按不同方向、速度退场；中心引出“在 AI、设计与交互的交汇处”，再衔接已有 About 内容。反向滚动恢复原构图和提示。
5. 手机缩短故事距离、降低卡片数量感与运动幅度；横屏压缩提示。减少动态效果时取消延长的 sticky 叙事和循环动画，仍完整阅读。
6. 今次范围是首屏到 About。后续时间轴、图谱、视频不在此轮伪装为完成。
