# PHASE 2 首屏改版第一轮

日期：2026-10-17。

## 改动
- 以完整大字标和四幅真实作品组成首屏，调整前后层次、尺寸与倾斜角度。
- 首屏底部加入可点击的中英文滚动提示、循环短轨迹和箭头，首屏内可见。
- 滚动时提示先退出，作品向外退场，标题上移并引出介绍过渡；反向滚动恢复。
- 增加封面进度反馈，分别适配手机和横屏；减少动态效果时提供直接阅读布局。
- CSS 位于 css/hero.css，组件位于 js/components/Hero.tsx，交互位于 js/hooks/useHeroMotion.ts。

## 验证
