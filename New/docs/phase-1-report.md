# PHASE 1 — 基础架构阶段报告

日期：2026-10-16。范围：六章节可运行骨架，不是最终视觉与交互成品。

## 已完成

- New 内独立 React + TypeScript + Vite 工程和锁文件；旧站根依赖及入口保持原样。
- HERO、ABOUT、JOURNEY、WORKS、SCREENS、CONTACT 六个连续滚动章节。
- 桌面与移动导航、当前章节提示、跳过导航入口、回到顶部、章节 hash 与刷新恢复。

- 两个旧版入口、统一资源地址处理；开发与生产预览支持 GitHub Pages 仓库子路径。
- 六视口测试、横屏、键盘、减少动态效果、历史导航、旧资源及 HTTP 入口检查。

- `npm run build`：类型检查与生产构建通过。产物 JS 343.12 kB，gzip 116.81 kB；CSS 9.51 kB，gzip 2.82 kB（不含按需加载的旧媒体）。
- `npm run test:unit`：3/3 通过，包含中文名称、特殊字符和路径逃逸拒绝。
- `PW_BROWSER_CHANNEL=msedge npm test`：9/9 通过（此处是环境变量说明，Windows 命令见 README）。实际浏览器为本机 Microsoft Edge。
- 六种视口宽度：375、430、768、1024、1440、1920；另测 844×390 横屏及减少动态效果。
- 图片实际加载、六章节可达、导航高亮、回到顶部、历史回退、hash 刷新、无横向溢出通过。
- 旧首页 HTML 和一张中文路径图片可通过生产子路径访问；这不代表旧站所有交互已回归验收。
- 源码检查未发现旧版已跟踪文件被修改。没有提交、推送或发布。

## 问题修复与决定记录

- 锚点刷新回到顶部：实测 hash 仍为 #about，但 scrollY=0，React 在浏览器初次锚点查找后才挂载目标。增加挂载后的白名单章节定位，回归测试通过。
- 独立审查发现省略尾斜杠时被旧站中间件误判为资源。放行该路径，让预览服务跳转到规范地址；失败测试转为通过。
- 独立审查发现原装饰橙作为标题文字的对比度为 2.804:1。为文字单独设置较深橙色，实测满足大字最低 3:1；背景和装饰保留原色。
- 在用户指定的本地 New 内隔离实现，没有创建另一个工作副本，便于直接查看与逐阶段继续。
- Chromium 下载慢，已停止并使用本机 Edge 完成验证；不将未完成下载描述为已安装。
