# 随机小票自动揉纸轮换

仅首页右上角“设计”小票每约 5 秒轮换一次，排除正在显示的作品及相同封面。绥远、矿山、灵溯三张固定票不参与轮换。

实现沿用用户附件的 React Bits PaperCrumple 完整纸张约束求解器、折痕法线和纸张材质。增加受控接口，计时器驱动揉起和展开，不模拟鼠标拖拽。Three.js 负责折纸渲染；html-to-image 将现有整张小票（封面、二维码、文字、票号、邮票齿边）生成透明纹理。

流程：预加载下一张封面 → 捕获当前票面 → 揉起 → 在纸团状态替换标题、封面、二维码和纹理 → 展开 → 恢复原 DOM 票面的视差与撕票交互。固定尺寸保持一致，不跳位；相邻两次作品不同。替换时重置新票的撕开状态。

鼠标悬停、键盘焦点、正在拖拽、打开弹窗、页面隐藏或小票离开视野时不开始新轮换。关闭动画偏好下直接切图，不创建 WebGL。WebGL/纹理准备失败时保留原 DOM 并降级为直接换图，不显示空白票。

组件：RandomArtworkTicket.tsx、PaperCrumple.jsx、PaperCrumple.types.ts。
样式：random-artwork-ticket.css、paper-crumple.css。
测试：random-ticket.spec.ts，覆盖桌面/手机整票揉碎、二维码更新、固定票不变、多次循环、离屏暂停、悬停暂停和减少动态效果。
