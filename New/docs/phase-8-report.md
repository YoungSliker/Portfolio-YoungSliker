# PHASE 8 验收与发布准备（2026-10-26）

## 已完成

- 首屏入口从 1,216,034 字节降至 601,362 字节；小票截图、纸张 Three.js 效果与二维码按需加载，图片独立缓存。
- 《小王子》和造型基础增加 H.264/AAC MP4 兼容版本，保留 MKV 原件；更新新旧站播放路径。
- 补充键盘跳转焦点与真实章节滚动位置检查。
- 用户选择保留 GitHub Pages，制作独立压缩副本，原始媒体不覆盖。1,203,567,075 字节降至 819,828,475 字节，约节省 31.9%，1342 个文件。
- 发布副本保持中文路径、文件格式和长图比例。宽图最大宽度 1920；JPEG 质量 88；大尺寸不透明 PNG 使用调色板，透明 PNG 保留透明通道。GIF、视频不经图片压缩流程。
- `verify-pages.py` 检查源文件哈希、产物哈希、图片可解码性、修改后的 PNG 透明通道和 950 MB 发布预算。发布副本目录为 `New/release/site`，清单为 `New/release/pages-manifest.json`。
- 新增 GitHub Actions 手动发布流程。默认只构建；勾选 publish 才会部署，当前没有提交、推送或修改远端 Pages 设置。
