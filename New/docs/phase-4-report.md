## 当前实现

- YOUNGSLIKER 中心 + 三大领域的放射空间构图；圆形作品缩略图、轻量直线连接，移除直角折线和矩形节点。
- 主案例直接连接 AIGC；绥远方志和微元灵溯基于用户已确认的交互体验内容，用虚线连接数字体验领域。
- 点击逐步展开，可以保留多个已展开分支。初始不铺开全部作品。
- 默认可直接拖动节点，连线实时更新；拖动空白区域移动画布。位置在本次探索中保留，重置恢复确定的初始构图，刷新不随机换位。
- 拖动阈值区分点选，避免拖完误打开概况。普通滚轮始终滚动页面；按钮缩放、适应画布和重置。
- 移除固定空白侧栏，点选后浮出概况，手机概况放在图下。保留键盘与完整尺寸分类按钮。
- 尊重减少动态效果，模块接近作品区再加载。现阶段为稳定预设坐标及直接拖动，不宣称已实现力导向弹性模拟。

## 文件与评估

`data/graph.ts`、`js/components/WorkGraph.tsx`、`css/work-graph.css`、`js/tests/work-graph.spec.ts`；入口在 `Works.tsx`，仍使用 React Flow。

React Flow 已支持本次放射坐标、真实节点拖动、连线跟随和分层展示，无需立即换库。若后续明确要求牵动邻居、弹性回落等物理行为，再评估 D3 力导向布局。当前不代表完整数据压力测试或真实手机硬件性能验收。
