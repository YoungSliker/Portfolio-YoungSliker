# PHASE 4 — 作品图谱技术原型

日期：2026-10-20。执行已确认计划书的 PHASE 4，当前为交互原型，视觉待用户审阅。

## 实现

- React Flow 独立模块，仅在接近作品区时加载，不在首屏初始化。
- 中心、三大领域、五个子分类、十二个真实作品。只展开当前分支，预设空间位置，不运行力导向布局。
- 自定义节点与折线连接；点击分类进入分支，点选作品聚焦并显示概况。
- 缩放按钮、适应画布、显式开启拖动、返回中心。普通滚轮继续滚动网页，关闭滚轮缩放。
- 桌面侧栏展示封面和简介，手机置于图谱下方；分类与作品同时有普通按钮入口，支持键盘操作，Escape 关闭概况并回到原按钮。
- 尊重减少动态效果设置。保留既有三个作品概况锚点，时间轴入口继续可用。

## 数据边界

三个主案例来自用户确认内容。其余名称、分类、封面来自旧站新媒体清单、APP 目录、视觉传达清单。仅作事实性简述，没有推断项目日期、职责或技能。

十二个作品：绥远方志、矿山*生态、微元灵溯、蜀韵天下、Kinect 表情交互、Kinect 手势水交互、学伴、颜茶阁、助残帮、库伦荞麦、万部华严经塔、创意归绥。

概况卡提供“浏览旧版完整作品集”入口，尚未承诺直达旧版单件详情。完整作品信息与详情路由留给 PHASE 5、6。

## 文件

- `data/graph.ts`：原型作品与分类数据。
- `js/components/WorkGraph.tsx`：图谱、操作与概况。
- `css/work-graph.css`：专用样式与响应式布局。
- `js/components/Works.tsx`：按可见区域懒加载接入。
- `js/tests/work-graph.spec.ts`：四种尺寸的全部分支、封面、键盘返回、缩放、滚轮及拖动测试。
- `package.json` / `package-lock.json`：新增计划书指定的 `@xyflow/react`。

## 技术评估

本阶段最多同时展示九个节点，React Flow 可以满足预设布局、分支展开、聚焦、缩放及拖动需求，建议继续使用。图谱独立 JS 约 186 KB、CSS 约 19 KB（未压缩传输前的构建文件大小），滚动接近作品区才请求模块。

已目视检查桌面和手机截图。手机全图较小，依靠分支聚焦与下方完整大小的作品按钮浏览；这仍是原型，后续可进一步调整视觉。当前不代表大型全作品图谱压力测试或真实手机硬件性能验收。

参考 API：[React Flow 官方文档](https://reactflow.dev/api-reference/react-flow)。

## 验证结果

类型检查及生产构建通过。Edge 单浏览器完整回归 47 项通过；最终补充画布复位后重新构建，图谱专项 5 项再次通过。覆盖 375、844、1440、1920 宽度、全部十二件作品的封面加载、节点与普通按钮操作、键盘返回、滚轮不缩放、显式拖动及复位。

并发测试曾遇到浏览器进程启动崩溃，改用单浏览器执行后通过；不将该次进程崩溃计为页面验收通过。截图位于 `docs/screenshots/phase4-graph-*.png`。
