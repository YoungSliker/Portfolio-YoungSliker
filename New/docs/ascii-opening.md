# 新版自动开场（2026-10-18）

目标：3.6 秒自动完成「流星撞击 → 地球滚落渐隐 → 流星亮点扩大 → 首页揭幕与邮票入场」。不再依赖滚轮推进；返回页面顶部不会重播。刷新页面可重播。

## 时间安排
- 0.05–0.75 秒：流星落向球顶；巨人在 0.35–0.60 秒先出现。
- 0.75 秒：地球出现，流星尾迹淡出；圆弧与原子同时出场。
- 0.75–1.25 秒：点阵圆弧从标记起点向外展开。
- 0.95–3.60 秒：采用一条不中断的进度轨道，连续完成滚落、渐隐、亮点扩大和首页揭幕。
- 亮点在地球即将落定时开始放大，与地球渐隐重叠，避免落定后停住再启动。
- 每条原子轨道由一条亮主线、两条 28% 透明度的点阵副线组成；副线位于主线内外两侧。
人物素材加载完后启动时间轴，避免慢连接导致人物错过入场。提供「跳过开场」按钮；提前向下滚动会直接完成开场，不劫持滚动。减少动态效果设置下直接显示静态首页。

## 实现与素材
- `js/hooks/useHeroMotion.ts`：单条 GSAP 自动时间轴、尺寸自适应、清理与跳过逻辑。
- `js/lib/atlasScene.ts`：从原素材采样人物轮廓；剔除原有静态几何线，独立绘制点阵圆弧路径与球体。圆弧使用手工拟合路径。
- `js/components/AsciiOpening.tsx` / `css/ascii-opening.css`：右侧 CSS 点阵原子、流星、跳过按钮、互动背景。
- 首页恢复一屏高度，无长滚动占位。
- 动画结束停止点阵绘制、原子旋转及背景交互。导航仍从 About 开始显示。
