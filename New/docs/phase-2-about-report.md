# PHASE 2 — 封面与个人介绍

2026-10-19。本轮完成 About 的可审阅版本，继续沿用用户已调整的首页；不改旧站，不发布。

## 设计与内容
- 暖白底、黑色中文大字、橙红强调。个人介绍沿用已有资料，未增加学历、奖项或工作经历。
- 三个交叠圆呼应首页圆环，领域切换时高亮相应圆。
- AIGC、数字体验、视觉传达三个领域支持鼠标及键盘展开；默认展开 AIGC。描述为创作方向，不构成未经证实的项目履历。
- 作品入口进入现有作品章节，经历入口进入下一章节；没有伪装成已完成的案例详情。
- 手机纵向阅读；横屏保持可滚动、不锁屏。

## 动效
原生滚动，首页轻微上移并淡出；About 各内容块随进入视野显现。反向滚动恢复，不使用强制停留或滚轮拦截。减少动态效果时直接显示内容。白点入场、刷新回首页、流体玻璃及小票保持现有行为。

组件 js/components/About.tsx；样式 css/about.css；滚动 js/hooks/useAboutMotion.ts；测试 js/tests/about.spec.ts。旧 About 样式从 sections.css 移除。导航在 About 使用同色背景。
