设计说明 | DESCRIPTION

《绥远方志：基于人智混合的呼和浩特史体验场景设计》以历史变迁与文化传承为核心，分筹备、驻军、融合、建成四篇章，串联绥远城政治、军事、文化、经济脉络。依托VR、AIGC及Agent技术，构建沉浸式交互场景：用户以第一人称视角探索城墙、接官厅等地标，动态壁画演绎历史事件，智能Agent实时答疑解惑。作品致力于打破文献壁垒，让观众在科技与历史的碰撞中，深度感知呼和浩特的地域文脉，唤醒文化保护意识，为边疆城市史志的数字化活化提供创新范本。

WEARABLE ARCHIVE / 01

让绥远方志 随身可戴入耳可听即时回应

可穿戴设备不只是便携硬件，而是借由软件支持、数据交互与实时反馈改变观众的感知方式。本方案以 Pico Neo 3 为头显原型，将 Qwen 2.5 史志智能体、ESP32-C3 语音控制板与 3D 打印 外设整合为沉浸式导览终端。

沉浸视听 实时反馈 Agent 记忆 PCB 外设

DEVICE FLOW

从语义到外设的导览链路

  1. 01方志记忆Qwen 2.5 承接绥远方志语义与讲解策略，为导览问答提供语料根据。
  2. 02语音交互用户提问被转成可处理的导览指令，回答再转为可听见的讲解声音。
  3. 03PCB 控制ESP32-C3 连接按键、音频与外设反馈，把软件指令落到硬件行为。
  4. 04佩戴反馈3D 打印外壳将内容带到观众身体侧，形成随身可听、即时回应的导览终端。
AGENT PLAN 语义规划与模型选型
MEMORY + TOOLS Agent 能力架构
ROLE + DIALOGUE 角色配置与对话测试

HARDWARE FLOW

硬件开发顺序

  1. 01电路与 PCB先用嘉立创 EDA 梳理 ESP32-C3、音频、按键与供电关系，再检查 PCB 正反面布局，为语音控制板下单打样。
  2. 02草图到结构以 Pico Neo 3 为头显原型，先推敲外设位置与导线走向，再用工业图纸校准尺寸、接口与佩戴结构。
  3. 03打印与组装元件到货后完成焊接测试，并通过 3D 打印外壳把控制板、导线与头显整合成可穿戴原型。
  1. 01语料整理将方志文本、角色设定与讲解目标整理成可检索的史志素材。
  2. 02模型接入以 Qwen 2.5 为主，对比多模型响应延迟、回答稳定性与讲解效果。
  3. 03角色测试配置记忆、语气、音色与对话样本，让导览回答更贴近现场。

HIDDEN HUNGER

隐性饥饿

隐性饥饿（Hidden Hunger）是指机体由于营养不平衡或者缺乏某种维生素及人体必需的矿物质，同时又存在其他营养成分过度摄入，从而产生隐蔽性营养需求的饥饿症状。

关注营养平衡，也关注那些不易被察觉的需求。
